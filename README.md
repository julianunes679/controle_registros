# Sistema de Registros em Python

Projeto simples em Python para cadastro e listagem de registros, com validação de dados e persistência em arquivo JSON.
Este projeto foi desenvolvido com foco em praticar lógica de programação, validação de entradas, organização de código e manipulação de arquivos.

##  Funcionalidades

- Cadastrar registros com:
  - Validação de nome (não vazio, tamanho mínimo, sem duplicidade)
  - Validação de idade (apenas números positivos)
- Listar todos os registros cadastrados
- Persistência de dados em arquivo `.json`
- Dados mantidos mesmo após fechar o programa


##  Conceitos praticados

- Estruturas de controle (`while`, `if/elif/else`)
- Funções
- Dicionários
- Tratamento de exceções (`try/except`)
- Manipulação de arquivos
- Serialização e desserialização com JSON
- Normalização e higienização de dados
- Organização de código
